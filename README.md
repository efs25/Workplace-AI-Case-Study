# Prairie Fire Partners operating system

**Eric Sanders | Prairie Fire Partners**

A case study and interactive demonstration of AI-assisted operating work built around expert judgment, explicit decisions and permissioned delivery.

## Start here

- [Read the case study](case-study.pdf): the operating problem, product ownership, workflow design, implementation boundaries and expert-informed feedback.
- [Open the playable portal demo file](portal-demo.html): use GitHub’s download control to save the HTML file, then open the downloaded file in a browser. It works offline after download. The GitHub file page previews source code; GitHub Pages is not enabled by this package.
- [View the demo source](portal-demo.html).

## What the demo shows

Three fictional client workspaces contain invented people, tasks, meetings, financial records and contribution data. Local interactions illustrate review, version approval and scoped views. All demo state is held in memory and resets on reload. There is no real authentication, production connection, external write or data collection.

The research feed contains attributed summaries and links to public sources reviewed November 10, 2026. It is a dated snapshot, not a live news feed. Source links open the original websites only when clicked. Fictional-client interpretations do not establish actual eligibility, legal obligations or commercial opportunities. Retain the item-level qualifications.

## Evidence and limits

The case study distinguishes working components and demonstrated review workflows from broader integration objectives. The browser demonstration is illustrative, not a production access-control test or proof that every depicted connection is live. No quantified productivity or financial return is claimed.
